# Portfolio Template — Vercel

Static portfolio template built with:
- HTML
- CSS
- Vanilla JavaScript

## Folder structure

```text
portfolio/
├── index.html
├── style.css
├── script.js
├── assets/
│   └── cv.pdf
└── README.md
```

## Before deployment

1. Replace `YOUR NAME`, location, phone, email, LinkedIn and GitHub.
2. Replace experience entries.
3. Replace skills.
4. Replace certification placeholders and credential URLs.
5. Replace education.
6. Put your CV at `assets/cv.pdf`.
7. Update the `<title>` and meta description.
8. Test all links locally.

## Local preview

Open `index.html` directly in a browser, or use VS Code Live Server.

## Vercel deployment

Push the folder to a GitHub repository, then import the repository in Vercel.
Vercel will deploy the static site and subsequent pushes can trigger automatic deployments.
